HOW TO RUN IT IN VISUAL STUDIO CODE
-----------------------------------
1. Download the ZIP file and extract it to a folder on your computer.
2. Open Visual Studio Code.
3. Select File > Open Folder and choose the extracted folder named:
   tmn3223_portfolio_starter
4. Open index.html.
5. To run the page, either:
   - double-click index.html in File Explorer to open it in a browser; or
   - install the Live Server extension in VS Code, right-click index.html,
     and select "Open with Live Server".
6. Edit the files and save them. Refresh the browser if needed.
